# 后台统一命名与数据字典

## 1. 命名原则

- 中文产品名称用于 UI、产品文档和错误文案。
- 领域名使用小写 snake_case，用于数据库、埋点合同和跨端 API。
- JavaScript 运行时对象可使用 camelCase，在网络边界与 snake_case 显式转换。
- 新代码不新增旧名称字段。兼容层可读取或投影旧字段，但必须标注 legacy。

## 2. 固定术语

| 禁用/旧名称 | V2 产品名称 | 代码领域名 | 规则 |
|---|---|---|---|
| 卡片、功能、Feature | 模板 | `template` | UI 和新 API 只用模板 |
| 标签页中的标签、分组 | 分类 | `template_category` | `ai_groups` 是兼容数据源 |
| `normal/new/hot` | 推荐标识 | `recommendation_badge` | 与分类分离 |
| Boss/Play 专区 | 展示专区 | `zone` | UI 显示老板专区/玩图专区 |
| 归属 | 展示位置 | `placement` | 由专区、分类和排序组成 |
| 图片 | 素材 | `asset` | 管理页名为素材中心 |
| 生图记录、历史 | 生成记录 | `generation_record` | 用户可见结果 |
| 任务 | 生成任务 | `generation_job` | 执行、重试和故障对象 |
| 积分、蛋、星光 | 星光 | `credit` | UI 仅显示星光；旧 `points` 兼容读 |
| 模型供应商 | 服务商 | `provider` | 仅系统配置/故障页展示 |
| 模型选择 | 能力策略 | `model_policy` | 运营默认不直接操作 Provider |
| `hang_count/la_count` | 废弃 | — | V2 隐藏并停止新写入 |

## 3. 模板字典

| 产品字段 | V2 字段 | 类型 | 说明 |
|---|---|---|---|
| 模板 ID | `template_id` | string | 稳定主键，兼容来源为 `ai_features._id` |
| 模板版本 ID | `template_version_id` | string | 不可变快照主键 |
| 模板名称 | `name` | string | 必填，删除/回滚确认字符串 |
| 模板类型 | `template_type` | enum | `image_to_image` / `text_to_image` |
| 分类 ID | `category_id` | string | 新模型字段；兼容 `group` |
| 展示位置 | `placements` | array | `{zone, category_id/group, sort}` |
| 推荐标识 | `recommendation_badge` | enum | `normal/new/hot` |
| 星光消耗 | `credit_cost` | number | 兼容层投影到 `points_cost` |
| 是否高清 | `enable_hd` | boolean | 兼容 `enable_upscale_print` |
| 主能力策略 | `model_policy` | string | 业务策略 ID |
| 主模型 | `model_call_id` | string | 兼容字段，高级配置 |
| 兜底模型 | `fallback_model_call_id` | string | 高级配置 |
| 生命周期 | `lifecycle_status` | enum | `draft/testing/ready/published/offline` |
| 旧发布状态 | `status` | number | 兼容投影：0/1 |

## 4. 核心实体

| 实体 | 集合 | 主要用途 |
|---|---|---|
| 模板兼容投影 | `ai_features` | 小程序线上读模型，V2 兼容写 |
| 模板版本 | `template_versions` | 发布快照、版本说明、回滚源 |
| 模板测试 | `template_test_cases` | 测试任务、模型、耗时、结果和错误 |
| 定时发布任务 | `template_publish_jobs` | 待发布快照、执行时间和结果 |
| 生成任务 | `generation_tasks` | 生图工作流权威状态 |
| 生成记录 | `generation_history` | 用户生成结果 |
| 原始埋点 | `analytics_events` | 180 天原始事件，按 `event_id` 幂等 |
| 用户日指标 | `daily_app_metrics` | DAU、新增、模板用户、触达率 |
| 模板日指标 | `daily_template_metrics` | 详情、生成、原图/高清保存和成功率 |
| 渠道日指标 | `daily_channel_metrics` | 渠道详情、生成和使用率 |
| 生成日指标 | `daily_generation_metrics` | 服务端任务成功率和失败原因 |
| 汇总任务 | `analytics_sync_jobs` | 定时汇总状态与异常 |
| 审计日志 | `audit_logs` | 操作人、动作、脱敏请求、结果 |

## 5. 统计类型与空值

- 人数类使用去重 `actor_id`，次数类使用幂等去重后的事件数。
- 比率字段使用 0—1 浮点数，不存储百分号字符串。
- 分母为 0 时必须存储/返回 `null`，禁止写成 0。
- 时间戳用 UTC 绝对时间，日键 `date` 按 Asia/Shanghai 转换为 `YYYY-MM-DD`。
- 今日日汇总 `is_provisional=true`，历史日为 `false`。

## 6. 建议索引

| 集合 | 索引 |
|---|---|
| `analytics_events` | `occurredAtMs ASC`；`eventName ASC, occurredAtMs ASC`；`templateId ASC, occurredAtMs ASC` |
| `template_versions` | `templateId ASC, versionNumber DESC` |
| `template_test_cases` | `templateId ASC, status ASC, createdAt DESC` |
| `template_publish_jobs` | `templateId ASC, status ASC, scheduledAtMs ASC`；`status ASC, scheduledAtMs ASC` |
| `generation_tasks` | `createdAt DESC`；`status ASC, createdAt DESC`；`featureId ASC, createdAt DESC` |
| `daily_template_metrics` | `date DESC, template_id ASC` |
| `daily_channel_metrics` | `date DESC, channel ASC` |
| `audit_logs` | `createdAt DESC`；`operatorUid ASC, createdAt DESC` |

## 7. 环境变量

| 名称 | 所在端 | 用途 |
|---|---|---|
| `BOOTSTRAP_TOKEN` | `adminApi` | 首个超级管理员一次性初始化口令 |
| `INTERNAL_FUNCTION_TOKEN` | 星光与生成云函数 | 仅内部退回/变更星光 |
| `VITE_CLOUDBASE_ACCESS_KEY` | 后台 Web 构建 | CloudBase Web 访问凭据，不提交到仓库 |
| `XPay_APP_ID` / `XPay_OFFER_ID` | 支付云函数 | 支付应用与米大师 ID |
| `XPay_APP_KEY_SANDBOX` / `XPay_APP_KEY_PROD` | 支付云函数 | 沙箱/生产密钥 |
| `XPay_ENV` | 支付云函数 | `1` 沙箱，`0` 生产 |

任何真实密钥不得出现在源码、文档示例、审计日志或前端运行时响应中。
