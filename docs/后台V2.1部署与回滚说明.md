# AI 造梦馆运营后台 V2.1 部署与回滚说明

## 发布范围

- 云环境：`cloudbase-5gmfinom29f48930`
- 云函数：`adminApi`
- 静态站点：`admin-web/dist`
- 管理后台：`https://makedream-admin.supersolo.tech/admin/index.html`
- 本轮不发布小程序，不修改小程序端现有代码和版本。

## 发布前检查

1. 运行 `npm test`，确认 V2/V2.1 契约测试全部通过。
2. 运行 `node --check cloudfunctions/adminApi/index.js`。
3. 运行 `npm --prefix admin-web run build`。
4. 核对 `config/admin-v21-indexes.json` 中的索引已存在或已创建。
5. 导出 `ai_features`、`admin_users`、`audit_logs` 三个集合的发布前快照。
6. 对 `migrateTemplatesV21` 先执行 `dryRun=true`，对账模板总数和各状态数量后再执行正式迁移。

## 发布顺序

1. 部署 `adminApi`，保留原函数版本作为回滚点。
2. 验证登录、管理员状态、模板列表和用户列表接口。
3. 执行模板迁移预演；对账通过后执行正式迁移。
4. 部署 `admin-web/dist` 到静态托管 `/admin/` 路径。
5. 使用超级管理员、模板编辑、运营和只读角色完成冒烟测试。

## 回滚

- 页面异常：将静态托管 `/admin/` 恢复到上一个发布包。
- 接口异常：将 `adminApi` 切回上一个稳定版本。
- V2.1 模板迁移只补充兼容字段，不删除旧字段；回滚函数和前端时旧数据仍可读取。
- 密码重置产生的认证密码修改不可通过代码发布回滚；应由超级管理员再次生成临时密码。

## 生产冒烟清单

- 新建仅含名称和类型的模板，保存后能在“全部模板、草稿、未归类”找到。
- 刷新模板列表后搜索、筛选、页码仍在 URL 中。
- 未配置展示位置的草稿发布检查失败，并定位到“展示与预览”。
- 用户列表默认加载 20 条，可按 OpenID 精确查询，OpenID 默认脱敏。
- 危险操作使用后台统一确认框，不出现浏览器原生确认框。
- 超级管理员可重置其他管理员密码，但不能重置自己。
- 缺失小程序埋点的看板指标继续显示“—”。
