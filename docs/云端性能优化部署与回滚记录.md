## 5. 回滚步骤

仅在生产异常时执行，先确认目标目录为上述备份目录。

1. 使用 `tcb fn code update <函数名> --dir <对应备份目录>` 依次恢复 `featureConfig`、`adminApi`、`points`、`aiGenerate`。
2. 将广告实验配置恢复为备份值：两个诊断广告开启，新人广告预加载仍为关闭；其余开关保持原值。
3. 冒烟验证旧 `getGroups/getList/getDetail`、星光余额、提交生成和后台管理操作。
4. 缓存集合属于派生数据，不需要删除。旧 `featureConfig` 不读取该集合，停用后不会影响业务数据。
5. 新增索引可保留；索引不改变数据语义，删除索引反而会增加回滚风险。
