# 小程序埋点与运营指标规范 V2

## 1. 数据原则

- 小程序统一通过 `utils/analytics.js` 的 `report()` 上报。
- 保留微信 `wx.reportEvent` / `wx.reportAnalytics`，同时写入自有 `analytics_events`。
- 服务端从登录上下文写入 `actor_id`，不信任客户端传入的用户 ID。
- `event_id` 是幂等键。重试上报不能重复累加指标。
- 不上报提示词全文、图片地址、昵称、手机号或其他个人信息。
- 原始事件保留 180 天，日汇总长期保留。

## 2. 标准事件

| 事件 | 触发时机 | 关键字段 |
|---|---|---|
| `app_open` | 小程序 `onLaunch` | `session_id, channel, scene_code` |
| `template_detail_view` | 模板详情页完成进入 | `template_id, zone, category_id` |
| `template_generate_click` | 用户点击“立即生成” | `template_id, template_version_id` |
| `generation_submitted` | 服务端接受生成任务 | `generation_id, template_id` |
| `generation_succeeded` | 生成任务最终成功 | `generation_id, duration_ms, model_route` |
| `generation_failed` | 生成任务最终失败 | `generation_id, error_code, provider` |
| `original_save_click` | 用户明确选择“保存原图” | `result_id, save_variant=original` |
| `original_save_succeeded` | `wx.saveImageToPhotosAlbum` 成功回调 | `result_id` |
| `original_save_failed` | 下载、权限或保存失败 | `result_id, error_code` |
| `hd_save_click` | 用户明确选择“保存高清图” | `result_id, save_variant=hd` |
| `hd_save_succeeded` | 高清图相册保存成功 | `result_id` |
| `hd_save_failed` | 高清生成、下载、权限或保存失败 | `result_id, error_code` |

兼容映射：

```text
feature_detail_view  -> template_detail_view
generate_click       -> template_generate_click
generation_submit    -> generation_submitted
generation_success   -> generation_succeeded
result_save_click    -> 仅兼容保留，不作运营指标源
```

## 3. 公共字段

```text
event_id              客户端生成的唯一事件ID
event_name            标准事件名
occurred_at           Unix毫秒时间戳
actor_id              服务端从登录上下文写入
session_id            本次启动会话ID
app_version           小程序/网站版本
template_id           模板ID
template_version_id   模板版本ID
generation_id         生成任务ID
result_id             生成记录/结果ID
save_variant          original | hd
channel               标准渠道
scene_code            微信进入场景值
referrer_app_id       来源小程序AppID
campaign_id           活动ID
zone                  展示专区
category_id           分类ID
source_page           事件页面
provider              服务商，仅故障数据
model_route           能力路由
duration_ms           耗时毫秒
error_code            标准错误码
```

## 4. 保存行为口径

1. 打开保存面板不上报 `original_save_click`或 `hd_save_click`。
2. 用户在面板中点击原图后立即上报 `original_save_click`。
3. 用户点击高清图后立即上报 `hd_save_click`，不等待高清生成成功。
4. 点击事件按次数累加，同一用户重复点击重复计数。
5. 只在 `wx.saveImageToPhotosAlbum` 成功回调后上报 `*_succeeded`。
6. 失败必须区分 `upscale_create_failed`、`upscale_failed`、`download_failed`、`download_status`、`permission_denied`和 `album_save_failed`。

## 5. 渠道字典与归因

| 渠道值 | 产品名称 |
|---|---|
| `app_jump` | APP跳转 |
| `recent_tasks` | 小程序任务栏/最近使用 |
| `mobile_search` | 手机端搜索 |
| `official_account` | 公众号文章或菜单 |
| `mini_program_jump` | 其他小程序跳转 |
| `share` | 好友或群分享 |
| `qr_code` | 普通码/小程序码 |
| `direct` | 直接访问 |
| `other` | 其他 |
| `unknown` | 无法识别 |

归因优先级：显式活动参数 → 已配置来源小程序 AppID → 微信进入场景 → `unknown`。首次进入写入会话上下文，详情、生成和保存事件沿用相同渠道。

## 6. 运营指标

| 指标 | 固定公式 | 权威数据源 |
|---|---|---|
| 每日活跃用户 | `distinct(actor_id where app_open)` | 自有事件，微信日趋势用于定稿校验 |
| 新增用户 | 当日首次 `app_open` 用户 | `analytics_users.firstSeenDate` |
| 使用模板用户 | `distinct(actor_id where template_generate_click)` | `analytics_events` |
| 模板触达率 | 使用模板用户 / 活跃用户 | 日汇总 |
| 保存原图用户 | `distinct(actor_id where original_save_click)` | `analytics_events` |
| 总使用率 | 全部立即生成点击 / 全部模板详情访问 | `daily_template_metrics` |
| 模板详情访问 Top 10 | 按单模板详情 PV 降序 | `daily_template_metrics` |
| 模板使用率 Top 10 | 单模板立即生成点击 / 详情访问 | `daily_template_metrics` |
| 高清图保存率 Top 10 | 单模板高清保存点击 / 原图保存点击 | `daily_template_metrics` |
| 渠道模板使用率 | 渠道立即生成点击 / 渠道详情访问 | `daily_channel_metrics` |
| 生图成功率 | 成功生成任务 / 提交生成任务 | `generation_tasks`，排除 `admin_debug` |

Top 10 比率榜不设最低样本门槛，但样本量小于 10 时显示“小样本”。高清图保存率的原图点击为 0 时返回 `null` 且不进榜。Tooltip 固定说明：“本指标为高清保存点击/原图保存点击，不代表文件最终保存成功率”。

## 7. 日汇总和接口

`analyticsAggregate` 每 5 分钟汇总今日和昨日，每次在 `analytics_sync_jobs` 记录状态。`adminAnalytics` 提供：

```text
getDashboardOverview
getDashboardUserTrend
getDashboardTemplateRankings
getDashboardHdSaveRankings
getDashboardChannelBreakdown
getDashboardGenerationPerformance
```

响应必须包含：

```text
dataStatus: available | partial | missing
updatedAt
isProvisional
missingEvents[]
```

## 8. 验收用例

- 只打开保存面板，原图/高清点击数均不增加。
- 点击原图两次、高清图一次，高清图保存率为 50%。
- 使用同一 `event_id` 重放两次，日汇总只增加一次。
- 原图点击为 0、高清点击大于 0 时，保存率为 `null` 且不进 Top 10。
- 分别模拟高清生成失败、下载失败、相册权限拒绝和相册保存失败，错误码必须不同。
- 跨越北京时间 00:00 的事件归入不同自然日。
- 生图成功率不统计 `source=admin_debug` 的任务。
