# 小程序性能优化前后对比报告

更新时间：2026-08-20  
候选包状态：仅本地代码，未上传、未提审

## 1. 结论

- 云端首页数据链路已经上线并达到预期：响应体下降87.5%—94.1%，缓存命中P95为50—61ms。
- 候选小程序按源码包边界估算，主包从430,980字节降至259,714字节左右，下降约39.7%，超过30%目标。
- `App.onLaunch`已缩减为云初始化、内存上下文和启动事件入队；登录、星光、管理员、新人任务和任务恢复均离开首屏关键路径。
- 首页业务请求由 `getGroups + getList` 合并为一个 `getHome`，并增加5分钟缓存、请求复用和首批8张渲染。
- 图片缓存模块已移除同步文件系统IO；单图状态变化不再重传整列数据。
- 当前只能确认静态契约、JS语法和云端生产指标。真实冷启动耗时、打开率和异常退出率必须由体验版真机及上线后We分析确认。

## 4. 启动关键路径

### 改造前

```text
onLaunch
→ 云初始化
→ login
→ 星光配置与余额
→ 管理员鉴权
→ 新人任务
→ 恢复并逐条轮询生成任务
→ 800ms内提交自有埋点
→ 首页分类请求
→ 首页模板请求
→ 同步读取/扫描图片缓存
```

### 候选版本

```text
onLaunch
→ 云初始化 + 内存上下文 + 埋点入队
→ getHome单请求
→ 首批8张卡片可交互
→ 延迟登录、任务批量恢复、埋点批量提交
→ 3秒后查询新人任务（不预加载广告）
→ 异步初始化图片缓存并合并写元数据
```
