## 2. 本轮性能优化改动

### 2.1 启动链路延迟化

- 来源：本轮性能优化
- 涉及页面：全局、首页、个人中心、模板详情、星光、反馈
- 用户可见变化：首屏优先展示模板；登录、任务恢复和新人任务稍后执行。
- 接口或数据变化：无旧接口破坏；首屏完成后批量提交自有埋点。
- 主要风险：直接打开分享页时延迟初始化时序。
- 必测用例：冷/热启动、直接分享链接、个人中心首次进入、切后台恢复。
- 是否影响线上旧版本：否，仅候选小程序使用。

### 2.2 首页单请求与客户端缓存

- 来源：本轮性能优化
- 涉及页面：老板专区、玩图专区
- 用户可见变化：缓存先展示；5分钟内返回页面不重复刷新；首批8张先出现。
- 接口或数据变化：使用新增 `featureConfig/getHome`，缓存键为专区/分类。
- 主要风险：缓存过期、分类切换和并发请求的状态覆盖。
- 必测用例：全分类、下拉刷新、断网缓存、快速切分类、后台排序发布后刷新。
- 是否影响线上旧版本：否，V1.4.7继续使用 `getGroups/getList`。

### 2.3 视口曝光与精确 `setData`

- 来源：本轮性能优化
- 涉及页面：首页卡片
- 用户可见变化：无；内部不再加载列表后一次性上报所有模板。
- 接口或数据变化：`feature_exposure`仅对进入视口卡片上报。
- 主要风险：观察器兼容性或切分类后重复观察。
- 必测用例：首屏/滚动/切分类曝光、同卡片去重、单图加载更新范围。
- 是否影响线上旧版本：否。

### 2.4 页面分包与支付隔离

- 来源：本轮性能优化
- 涉及页面：模板详情、等待、结果、星光、历史、反馈
- 用户可见变化：首次进入非首页页面可能出现一次分包加载，之后复用。
- 接口或数据变化：页面URL不变；支付实现移动到星光分包。
- 主要风险：分包路径、旧分享链接、分包首次加载。
- 必测用例：所有旧URL、Tab跳转、详情→等待→结果、个人中心→星光/历史/反馈。
- 是否影响线上旧版本：否。

### 2.5 等待页插屏按需恢复

- 来源：本轮性能优化（恢复线上V1.4.7能力并重构隔离）
- 涉及页面：生图等待页
- 用户可见变化：等待页按云端开关展示插屏；首页不加载插屏代码。
- 接口或数据变化：读取 `adTelemetry/getExperimentConfig`，结果写入插屏遥测。
- 主要风险：广告关闭导致页面生命周期切换、广告加载失败影响生成。
- 必测用例：展示/关闭、无广告、加载失败、离开页面、任务先完成。
- 是否影响线上旧版本：云端开关保持兼容，旧版行为不变。

### 2.6 图片缓存异步化

- 来源：本轮性能优化
- 涉及页面：首页及复用图片加载器的详情/结果/历史
- 用户可见变化：缓存损坏时自动回退网络图；首屏不再做同步磁盘扫描。
- 接口或数据变化：缓存元数据升级为V2，最多2秒合并写入，旧缓存不强迁移。
- 主要风险：首次升级缓存命中率暂时下降、文件API机型差异。
- 必测用例：二次启动命中、损坏单项、100MB淘汰、切后台补写、弱网。
- 是否影响线上旧版本：否。

### 2.7 生成任务批量恢复

- 来源：本轮性能优化
- 涉及页面：全局生成完成提醒
- 用户可见变化：后台遗留任务恢复更快；过期任务不再持续轮询。
- 接口或数据变化：调用新增 `aiGenerate/getTaskStatuses`，最多20个且仅返回当前用户任务。
- 主要风险：旧本地任务数据、20条上限、前后台定时器恢复。
- 必测用例：0/1/5/20个任务、成功/失败、24小时过期、后台暂停。
- 是否影响线上旧版本：否，旧单任务接口仍保留。

### 2.8 埋点队列延后与失败缓存

- 来源：本轮性能优化
- 涉及页面：全局
- 用户可见变化：无；启动期不与首页抢云调用。
- 接口或数据变化：事件先入内存，首屏完成或3秒后批量提交；失败最多缓存60条。
- 主要风险：极短会话退出、缓存重放和幂等。
- 必测用例：首屏前事件、首屏后批量、断网退出、下次启动重试、重复事件去重。
- 是否影响线上旧版本：否。

### 2.9 运营看板埋点归因补齐

- 来源：本轮埋点核查补齐。
- 涉及页面：首页、模板详情、生图等待、结果页。
- 用户可见变化：无。
- 接口或数据变化：首页点击模板时携带实际 `sourceZone/sourceGroup`，并沿详情、等待和结果链路传递；详情、生成、保存事件使用用户真实入口的专区和分类，不再默认取模板第一条展示位置。
- 主要风险：中文分类名称的URL编码与旧分享链接兼容。
- 必测用例：同一模板分别从老板/玩图专区及不同分类进入；核对详情、生成提交、原图保存、高清保存事件的专区和分类；不带新参数的旧分享链接仍可打开。
- 是否影响线上旧版本：否，仅候选小程序使用；云端字段已向后兼容。

### 2.10 玩图首页诊断Banner恢复

- 来源：本轮产品调整（恢复线上V1.4.7能力）。
- 涉及页面：玩图专区首页。
- 用户可见变化：APP外部跳转场景使用外部诊断广告位，其他进入场景使用内部诊断广告位；老板专区不展示。
- 接口或数据变化：异步读取 `adTelemetry/getExperimentConfig`；不使用同步本地存储，不恢复新人广告预加载。
- 主要风险：广告请求增加网络竞争、广告位加载失败或进入场景识别异常。
- 必测用例：场景1069、普通内部进入、老板专区、无广告填充、弱网、关闭云端开关。
- 是否影响线上旧版本：云端开关恢复后，V1.4.7的诊断Banner也会恢复。

### 2.11 👍/👎计数展示与弹窗真机素材修复

- 来源：真机回归修复。
- 涉及页面：首页模板卡片、模板详情、新人好礼弹窗、生成加速弹窗。
- 用户可见变化：首页、详情和结果评价统一使用 👍/👎，不再直接展示“夯/拉”文字；两个奖励弹窗背景恢复。
- 接口或数据变化：无。`featureConfig/getHome` 与 `getDetail` 已继续返回真实计数字段，数据库票数未被修改。
- 素材变化：两张透明 PNG 使用内容哈希文件名上传到 CloudBase 存储，前端通过 `wx.cloud.downloadFile` 异步下载、校验文件大小、持久缓存并预解码；PNG 源文件移至 `assets-source/reward-modal/`，不再进入小程序代码包。包内图片和音频总量由 268.13 KiB 降至 63.64 KiB。
- 体验保护：确认新用户可领取后先预加载礼包背景，模板详情页打开后预加载加速背景；弹窗只使用已完成解码的本地路径。首次弱网失败时显示完整 CSS 兜底，本次弹窗不在可见后补图，避免闪烁和布局跳变。
- 云端资源：`reward-assets/v1.4.8/new-user-gift-bg-4b34144b.png`、`reward-assets/v1.4.8/generation-boost-bg-f2f97dfe.png` 已上传，回下载 SHA-256 与源文件完全一致。
- 主要风险：旧预览包仍包含旧路径；必须重新编译生成新预览包，并验证云存储下载权限、本地缓存和断网兜底。
- 必测用例：非零和零票模板的首页/详情显示；礼包和加速背景首次加载、二次缓存、弱网、断网兜底；安卓与 iPhone 真机重新扫码验证。
- 是否影响线上旧版本：否，仅候选小程序发版后生效。

### 2.12 用户生成图“是否被保存”

- 来源：本轮运营评估需求。
- 涉及页面：小程序结果页埋点、后台 V2 图片中心 → 用户图片。
- 用户可见变化：小程序端无新增操作；后台仅对 `generated_results/` 图片展示“是 / 否 / —”，其他目录留空。
- 接口或数据变化：复用 `original_save_succeeded`、`hd_save_succeeded`，无需新增重复事件；`analyticsIngest` 补充把生成成功事件的 `history_id` 映射为 `result_id`，`adminApi/listImages` 按生成记录关联保存事件。
- 口径：“是”=至少一次相册保存成功；“否”=已确认接入本版精确埋点但没有成功事件；“—”=历史版本或关联缺失，不能判断。点击保存但下载/权限/相册保存失败不计为已保存。
- 部署状态：`analyticsIngest`、`adminApi` 和新版后台 V2 页面已于 2026-08-21 部署；候选小程序尚未发版，因此历史图片多数仍会显示“—”。
- 主要风险：候选小程序发版前没有完整的精确保存事件；必须继续区分“未保存”和“历史数据无法判断”。
- 必测用例：原图成功、高清成功、权限拒绝、仅打开保存面板、从未保存、历史图片、`uploads/` 和 `generated_upscaled/` 目录。
- 是否影响线上旧版本：接口向后兼容；未发新版小程序前不会产生完整的未来判定数据。
