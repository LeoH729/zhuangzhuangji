# AI造梦馆项目目录隔离规范

生效日期：2026-08-21

## 固定目录

```text
F:\OPC_SuperSolo\Ai造梦馆\
├─ zhuangzhuangji-main\
│  ├─ miniprogram\       微信小程序源码，微信开发者工具唯一编译根
│  ├─ admin-web\         运营后台源码
│  ├─ cloudfunctions\    微信云函数
│  ├─ cloudbase\         云开发与静态托管配置
│  ├─ cloudrun\          服务端运行服务
│  ├─ tests\             跨模块契约测试
│  ├─ scripts\           部署、迁移和验证脚本
│  └─ docs\              产品与技术文档
└─ zhuangzhuangji-web\   Next.js网站独立项目
```

## 开发规则

1. 微信开发者工具始终打开 `zhuangzhuangji-main`，由 `project.config.json` 的 `miniprogramRoot=miniprogram/` 限定编译范围。
2. 小程序页面、组件、工具、配置和图片只能放入 `miniprogram/`。
3. 运营后台只在 `admin-web/` 开发，不得复制到 `miniprogram/`。
4. 云函数只在 `cloudfunctions/` 开发，通过云开发CLI部署，不得复制到 `miniprogram/`。
5. 网站只在同级 `zhuangzhuangji-web/` 开发，网站的 `.next`、`node_modules`、日志和环境变量由网站自己的 `.gitignore` 管理。
6. 小程序与网站通过版本化接口和数据契约共享后端能力，禁止通过跨目录复制源码复用功能。
7. 需要共享的纯协议或字段规范放入 `docs/`；需要共享代码时应提取为独立包并明确构建边界。

## 启动方式

小程序：

```text
微信开发者工具打开 F:\OPC_SuperSolo\Ai造梦馆\zhuangzhuangji-main
```

网站：

```powershell
Set-Location 'F:\OPC_SuperSolo\Ai造梦馆\zhuangzhuangji-web'
npm run dev
```

后台：

```powershell
Set-Location 'F:\OPC_SuperSolo\Ai造梦馆\zhuangzhuangji-main\admin-web'
npm run dev
```
