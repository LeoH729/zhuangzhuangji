# 妆妆记

一款帮助用户记录化妆品过期日期并提供到期提醒的微信小程序。

## 功能特点
- 📸 拍照或从相册上传化妆品图片
- 📝 记录化妆品名称、类别、购买日期、过期日期和备注
- ⏰ 过期前自动提醒（默认30天）
- 📊 直观展示化妆品列表及过期状态
- ✏️ 支持编辑和删除化妆品记录
- 🔍 详情页展示完整信息和剩余天数

## 项目结构

## 环境要求
- 微信开发者工具
- Node.js (可选，用于代码管理)
- 微信小程序账号（需注册并获取AppID）

## 如何使用
1. 克隆或下载本项目到本地
2. 打开微信开发者工具
3. 导入项目，填写您的小程序AppID（在project.config.json中修改）
4. 点击编译运行即可预览

## 配置说明
- 默认提前提醒天数：30天（可在app.js中修改reminderDays变量）
- 支持的化妆品类别：护肤、彩妆、香水、美发、身体护理、工具、其他
- 数据存储：使用微信小程序本地存储（wx.setStorageSync/wx.getStorageSync）

## 注意事项
- 图片上传功能需要在微信开发者工具中开启本地设置中的"不校验合法域名"
- 提醒功能依赖小程序的模态框提示，需要用户允许通知
- 本地存储数据会保存在用户设备上，卸载小程序会导致数据丢失
